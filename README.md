# Arrow Puzzle

A 2D offline arrow puzzle game for Android.

**Current status:**  
Early development / v0.1.0

## Features Currently Implemented
- Offline gameplay
- Arrow-based puzzle mechanics
- Arrow movement animation
- Blocked-arrow feedback
- State-driven animation architecture
- Multiple puzzle levels
- Customizable arrow color and board themes
